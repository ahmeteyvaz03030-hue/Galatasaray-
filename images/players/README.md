# Oyuncu Fotoğrafları

Bu klasöre bir oyuncunun/yöneticinin adına göre isimlendirilmiş bir `.jpg` dosyası koyarsan,
sayfa (kadro kartları, ilk 11 sahası, yönetim kartları) o fotoğrafı otomatik olarak
kullanır. Fotoğraf yoksa forma numarası / baş harfler gösterilmeye devam eder — hiçbir şey
bozulmaz.

**Dosya adı kuralı:** isim küçük harfe çevrilir, Türkçe karakterler sadeleştirilir
(ş→s, ğ→g, ü→u, ö→o, ç→c, ı→i) ve boşluklar tire (`-`) ile değiştirilir.

Örnek: **Victor Osimhen** → `victor-osimhen.jpg`

## Nasıl eklerim?

1. GitHub'da bu repoya git, `images/players/` klasörünü aç.
2. "Add file → Upload files" ile fotoğrafı yukarıdaki tam dosya adıyla yükle (örn. `victor-osimhen.jpg`).
3. Commit et — sayfa bir sonraki ziyarette fotoğrafı otomatik gösterir.

**Not:** Telif hakkı olan resmi kulüp/basın fotoğraflarını herkese açık bir sayfada
kullanmak hak ihlali olabilir; kendi çektiğin veya kullanma iznin olan fotoğrafları
tercih et.

Kadroya yeni bir oyuncu eklersen, dosya adı kuralı aynı şekilde çalışır — yukarıdaki
tabloya bakmana gerek yok, sadece adını küçük harfe çevirip boşlukları tireyle değiştir.
